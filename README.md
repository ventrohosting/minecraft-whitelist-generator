# Minecraft Whitelist-Generator

Spielernamen eingeben, UUIDs von Mojang abrufen oder für Offline-Server berechnen und die fertige whitelist.json herunterladen: kostenlos und ohne Anmeldung.

**Online nutzen:** [Minecraft Whitelist-Generator](https://ventrohosting.com/tools/minecraft-whitelist-generator) · Demo: https://dannytheone.github.io/minecraft-whitelist-generator/

## Funktionen

- Bis zu 50 Spielernamen auf einmal
- Online-Modus: echte UUIDs von Mojang; Offline-Modus: UUID wie der Server sie aus dem Namen berechnet
- Fertige whitelist.json zum Kopieren oder Herunterladen

## English

Minecraft whitelist generator: enter player names, get their UUIDs from Mojang (or compute offline-mode UUIDs) and download a ready whitelist.json.

Use it online: https://ventrohosting.com/tools/minecraft-whitelist-generator

## Selbst hosten

Statische Seite ohne Build-Schritt und ohne Abhängigkeiten: `index.html` und `tools.js` auf einen beliebigen Webserver legen oder GitHub Pages aktivieren. Die Abfrage nutzt die öffentliche API von ventrohosting.com.
